# FocusHub Writing Assistant

A powerful browser extension that enhances your writing experience with AI-powered assistance, real-time suggestions, and productivity tools to help you write better, faster, and more confidently.

## 🌟 Overview

FocusHub Writing Assistant is a comprehensive browser extension designed to be your personal writing companion. Whether you're composing emails, writing blog posts, drafting social media content, or working on professional documents, this extension provides intelligent assistance to improve your writing quality and productivity.

## ✨ Key Features

- **AI-Powered Writing Suggestions**: Get real-time grammar, spelling, and style recommendations
- **Tone Adjustment**: Adapt your writing tone for different contexts (professional, casual, friendly, formal)
- **Content Enhancement**: Receive suggestions to improve clarity, conciseness, and impact
- **Multi-Platform Support**: Works seamlessly across popular websites and text editors
- **Privacy-Focused**: Your writing stays private and secure
- **Customizable Settings**: Tailor the assistant to match your writing style and preferences
- **Dark Mode Support**: Comfortable writing experience in any lighting condition

## 🚀 Installation

### From Chrome Web Store
1. Visit the [Chrome Web Store](#) (link coming soon)
2. Click "Add to Chrome"
3. Confirm the installation
4. The FocusHub icon will appear in your browser toolbar

### From Source
1. Clone this repository:
   ```bash
   git clone https://github.com/gradykorchinski-ship-it/FocusHub-Writing-Assistant.git
   ```
2. Navigate to your browser's extension page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension directory

## 💡 How to Use

1. **Activate the Extension**: Click the FocusHub icon in your browser toolbar or use the keyboard shortcut
2. **Start Writing**: Begin typing in any text field on supported websites
3. **Review Suggestions**: The extension will automatically highlight potential improvements
4. **Apply Changes**: Click on suggestions to accept them or dismiss them if not needed
5. **Customize Settings**: Access preferences through the extension popup to adjust assistance levels

## 📝 Development

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Modern web browser (Chrome, Edge, Firefox, or Brave)

### Setup Development Environment
```bash
# Install dependencies
npm install

# Run development build
npm run dev

# Build for production
npm run build

# Run tests
npm test
```
